# 虎门大桥视频数字孪生展示

本仓库包含可在本地运行的前端源码，以及页面实际使用的全部静态资源：两个案例的处理后视频、测点轨迹 JSON 和位移 CSV。两个视频是独立案例；原始四宫格监控视频、模型权重和分析中间文件不在本仓库内。

## 本地运行

需要 Node.js。克隆仓库后运行：

```bash
npm ci
npm run dev
```

浏览器打开终端显示的本地地址（默认 `http://127.0.0.1:5173/`）。生成静态网页可运行 `npm run build`，输出位于 `dist/`。

## 文件说明

- `src/`、`index.html`：Vite + Three.js 前端与三维示意模型。
- `public/video/`：两个案例右下角处理画面的视频，已修正为方形像素，和选点坐标使用同一显示比例。
- `public/data/`：测点、时序轨迹和位移数据；CSV 可从页面下载。

页面上的米值使用公开箱梁高度进行**名义尺度换算**。缺少相机标定和同步实测数据，不能将其视为工程测量或安全评估结论。三维模型用于展示相对位置与振动形式，不是虎门大桥的精确结构模型。

公开仓库仅提供查看和运行，不附带对视频或数据的再使用授权。
